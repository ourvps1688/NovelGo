# 角色设计

## 何时使用
用户说"创建角色""这个人设有什么问题""角色弧光怎么写""人设没记忆点""配角太工具人"时自动加载。

**对齐声明（必读）**：本书若已选题材约束卡（genreTemplates），卡片的「三定律 / 禁忌 / 爽点密度」是人设的最高约束，优先级高于本技能。本技能只补"如何设计人设"，**不覆盖题材卡**。例：爽文卡已硬编码「主角绝对中心、有仇不过夜、禁虐主、金手指一致性」，人设不得安排主角"学会原谅仇人 / 因缺陷失去所爱 / 临时无依据开挂"；悬疑卡写「禁无敌主角，侦探也会误判、付出代价」，则允许主角有缺陷并承担后果——**以活动卡片为准，勿套用其他流派的教义**。

## 核心原则：先定流派，再选角色教义
本书若已选题材卡，优先以卡内「冲突发动机 / 禁止漂移 / 爽点密度」为人设边界，再映射到下方最接近的教义档案。未选题材卡时，自行判定本书最可能的流派后套用。多数书是**混合流派**，先定主教义，再叠加其余。

### 角色教义档案（可混合，不止一种）
- **① 升级 / 目标驱动型** — 适用：玄幻、高武、修真、西幻、网游、电竞、爽文、历史争霸 / 搞事。
  - 欲望 = 引擎（复仇 / 登顶 / 变强 / 打脸），读者想看它被满足。
  - 弧光默认**平面 / 能力成长**（同一个狠人越来越强，不是学会柔软）。
  - 缺陷 = 可爱怪癖 / 底牌，非致残创伤；创伤若是起因，功能是**目标燃料**。
  - ⚠️ 与力量体系强耦合：主角人设须体现其核心金手指 / 修炼逻辑（参见 worldbuilding-design）。
- **② 经营 / 积累型** — 适用：种田、日常、美食、基建、技术流、部分硬科幻。
  - 低冲突、慢节奏，爽点来自「积累感 / 技术碾压 / 温馨日常」而非打脸。
  - 主角多**平面稳定人格** + 强经营目标；群像 / NPC 极重要（村庄 / 团队 / 顾客），**配角功能化权重最高**。
  - 缺陷更忌「导致失去」；虐主同样不可接受。
- **③ 情感 / 关系驱动型** — 适用：女频言情、甜宠、CP 向、乙女（可跨分组出现）。
  - CP 钩子与化学反应是核心；可无创伤（甜宠）也可有（虐恋）。
  - 双方须有「天然张力」（身份对立 / 目标冲突 / 互补缺陷）。卖点化的 CP 感权重最高。
- **④ 解谜 / 真相驱动型** — 适用：悬疑、推理、智斗、部分科幻。
  - 主角 = 高智平面（分析师 / 侦探），驱动是「真相 / 解题」。
  - **允许误判与代价**（悬疑卡「禁无敌主角」），反派常为负向弧。道德灰区可接受。
- **⑤ 心理 / 弧光型** — 适用：虐恋、重生复仇、部分文学向、部分科幻。
  - 启用纯文学「欲望 vs 需求 / 谎言 / 创伤-缺陷链」：想要爱情的人真正需要自我接纳；想要复仇的人需要放下执念——需求可颠覆欲望，在此成立且动人。
  - 仍服从题材卡禁止漂移。

> 混合示例：「玄幻 + 言情」= ① + ③；「种田 + 甜宠」= ② + ③；「悬疑 + 重生」= ④ + ⑤；「历史 + 权谋」= ① + ④。

## 工作流

### 1. 定教义
按题材 / 流派从 ①–⑤ 选主教义（可叠加），并标注"假定 X 流派，若实为 Y 请告知切换"。

### 2. 欲望 / 目标（按教义表述）
- ① / ④：写出主角**最具体的目标**与里程碑（第几章拿到什么、解开什么）。
- ②：写出**经营目标**（积累什么、建成什么），成功标准可量化。
- ③：写出**关系目标 / 张力**（想靠近谁、与谁对抗）。
- ⑤：区分 want 与 need（need 为内在成长落点，参考 Weiland《Creating Character Arcs》）。
- 共通：主角须有**一个让读者替他着急的执念**。

### 3. 谎言 / 内核
- 仅 ⑤ 强依赖（Lisa Cron《Story Genius》：角色相信的最大错误认知）。
- ① / ④ 可给"表层误判"（如低估对手），不要求治愈收尾。
- ② / ③ 通常稳定人格，谎言层可省。

### 4. 创伤与缺陷（按教义分流）
- ①：创伤 = 目标燃料；缺陷 = 怪癖 / 底牌；代价在"爽点迟到"而非"失去所爱"。
- ②：缺陷忌致失；以怪癖 / 执念为主。
- ④：缺陷可真实致代价（误判、翻车），服务解谜张力。
- ⑤：创伤为具体画面（Truby 缺陷-需求链），缺陷有真实代价。

### 5. 弧光方向（按教义选默认）
- ① 默认平面 / 能力成长；② 平面稳定；③ 双方可平面（甜宠）或一方弧光（虐恋）；④ 高智平面；⑤ 正向 / 负向 / 平面三选一。
- "角色没变化"不再一律判缺陷——① / ② / ④ 下"不变"是设计意图。

### 6. 配角功能化（共通，强烈推荐）
每个配角至少占一个功能槽（可叠加）：
① 推动主角（挑战 / 目标催化剂 / 打脸救场）② 代表一种世界观或价值观（对比映射）③ 创造情节节点（信息 / 误会 / 冲突）④ **【网文专属】战力 / 资源梯队**（垫脚石 / 同级对手 / 天花板，服务升级节奏）⑤ **【网文专属】关系槽位**（CP 感 / 师徒 / 兄弟 / 反差搭档 / 拖后腿猪队友）⑥ **【网文专属】爽点催化剂**（虐点制造机 / 迷妹迷弟 / 捧哏）。
- ② 流派下群像权重最高，优先保证村庄 / 团队 / 顾客各有清晰功能。
不占槽位者考虑合并。参考 Forster 扁形 / 圆形区分：配角可扁（功能明确），主角与主要对手须圆形（多层矛盾）。

### 7. 卖点化（网文人设记忆点引擎，共通）
文学理论不教"怎么让人设让人记住"，专补此步：
- **标签化**：1–2 个一句话标签（"腹黑毒医""社恐剑修""财迷女帝"），可视觉化、可梗化。
- **反差萌**：表层 vs 里层反差（高冷 / 社恐、杀伐果断 / 路痴、霸总 / 猫奴）。
- **CP 感 / 关系钩子**：含感情线时设计天然张力（身份对立 / 目标冲突 / 互补缺陷）。
- **记忆点动作 / 台词**：代表性小动作或口头禅，反复出现即成符号。
- **自检**：用一句话向未读者介绍主角，记不住 / 不想追即失败。

## 信号检查

| 症状 | 诊断 | 对策 |
|------|------|------|
| 角色只有特征清单无内在驱动 | 缺清晰欲望 / 执念 | 回到步骤 2，写清"最想要什么、读者为何替他急" |
| 爽文 / 男频主角被安排"学会原谅 / 柔软 / 失去所爱" | 误套了 ⑤ 或其他流派教义 | 切回 ①：欲望即引擎，服从题材卡禁虐主 / 有仇不过夜 |
| 悬疑主角全知无敌、从不出错 | 误套了 ① 的"胜任型" | 切 ④：悬疑卡禁无敌主角，给误判与代价空间 |
| 种田 / 日常主角整天打打杀杀 | 误套了 ① 的冲突逻辑 | 切 ②：低冲突积累，群像与经营目标为主 |
| 角色从头到尾没变化 | ① / ② / ④ 下可能是设计意图 | 先确认教义，再决定是否需"影响世界 / 成长" |
| 配角比主角有趣 | 主角缺执念或卖点 / 群像失衡 | 补更大执念 + 标签反差；② 下补足功能化 NPC |
| 人设记不住、没话题 | 缺卖点化 | 走步骤 7：补标签 / 反差 / CP 钩子 / 记忆点 |
| 弧光靠"突然懂了" | 跳过小选择累积（⑤） | 每章至少一个展示微调的小选择 |
