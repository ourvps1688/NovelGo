# 章节写后自检

## 何时使用
刚完成一个章节的写作或续写之后主动使用；或用户要求"检查这章""这章达标吗""自检一下"时加载。

## 工作流

写完一章后，**先不要汇报完成**，按下面的清单逐项核对，然后给出简短的自检报告。任何一项不达标，先修复再交付。

> **系统级大纲写前门禁（已生效）**：若本书已存在任意大纲，正文写入管线会强制「先建大纲再写正文」——`chapters/new.md` 直接建正文会被拒绝，要求改走 `outlines/new.md`；已有章节若大纲文件为空（不足 30 字）写正文也会被拒。无大纲的本书按即兴写作放行。因此写正文前请确认本章大纲已就绪。

### 1. 字数门槛
- **以真实字数准，不要自己估算**：通过章节列表 / get_chapter 等工具返回的「· N 字」(word_count) 读取本章实际字数。系统的字数统计 = 中文字符数 + 英文单词数，比凭感觉估的准得多。
- **目标字数来源**：优先取本章大纲「基调与字数」里你写的预估字数；若大纲没写预估字数，但有激活的「创作约束 / 题材约束」写明了单章字数下限（如爽文不少于 3500、悬疑不少于 3000），以该下限为目标；都没有则默认基准 **2000 字**。
- **判定与一次性补写**：实际字数低于目标的 **70%** 视为不达标，必须扩写后才能交付；达到 70% 即视为软通过。但"达标"指的是**达到目标字数本身**，不是卡在 70%。
  - **一次性补足，禁止反复小步追加**：判定不达标时，**只读一次 word_count** 算出缺口（目标 − 当前），然后**用一次 edit / 追加操作把缺口（再上浮约 15% 缓冲）一次性补齐**。不要采用「补一点 → 重读 word_count → 再补一点」的多轮循环——既浪费轮次也容易写水。补完后最多再读一次 word_count 确认已达标即可，不要来回拉锯。
  - 扩写内容必须是**有叙事功能的增量**（推进情节 / 深化场景 / 补充感官细节 / 落实现有伏笔），严禁用凑数、重复、注水段落凑字数——字数达标但内容空洞同样不通过。

### 2. 推进与功能
- 本章是否推进了至少一条主线（情节/关系/认知三选一），纯水文不过关。
- 章内至少有一个"状态改变"：主角处境、角色关系、读者认知三者必有其一发生变化。

### 3. 情绪流与爽点
- 检查情绪曲线是否有起伏：压抑→释放、危机→化解、铺垫→爆发，至少完成一次完整循环。
- 对照题材约束（若创作偏好中配置了"创作约束"）核对爽点密度：爽文章节至少 1~2 个明确爽点；非爽文题材检查是否有等效的"满足感节点"（悬念揭示、情感兑现、谜题推进）。
- 章末必须有钩子：新悬念、危机升级、反转预告三者之一。

### 4. 禁忌核对
- 无元引用（不得出现"读者""作者""本书""上文提到"等破墙表达）。
- 无现实人名、现实品牌、现实地名（架空名除外）。
- 无吃书：本章内容不得与已确立的设定、时间线、人物关系矛盾；引用设定前先查（可用 memory 检索或设定文件核对）。
- 主角处理符合题材约束（如爽文禁虐主、有仇不过夜）。

### 5. 正文格式核对
- 无「一、二、三、四」或「（一）（二）」类序号充当段落/小节分隔符——正文用叙事自然分段，不要给场景或情绪段强行编号。
- 无破折号「——」等 AI 味硬伤：正文绝对禁用破折号（系统写入管线硬校验，包含即提交失败）；此外「X 一般」式精致比喻、无情绪声线模板（声音不大却/平静无波）、命运/开端套话（命运的齿轮/反击才刚刚开始/这一刻终于明白）、「他不知道的是/殊不知」式上帝视角预告、模板化身体微表情（眼中闪过一丝/嘴角勾起一抹/瞳孔微缩/指节泛白等）也会被系统硬拒，写作时直接规避。若被系统拒绝：只替换命中句、其余正文原样保留重提，**不要重写整章**。

### 6. 一致性抽查
- 本章出场角色的名字、称呼、性格口癖与人物卡一致。
- 时间线连续：与上一章的时间、地点衔接无跳跃矛盾。
- 伏笔处理：本章若回收伏笔，确认伏笔登记过；本章若埋伏笔，确认足够隐晦且可回收。

### 7. 去 AI 味复核（advisory，非硬伤）
以下项系统已在写入管线硬卡最明确的几种（破折号、「X 一般」比喻、无情绪声线模板、命运/开端套话、「他不知道的是」、模板化身体微表情），本项用于人工/自检复核更隐蔽的 AI 指纹——命中不必全删，但需逐处判断是否可落地为动作、对话或后果：
- **合法常用语（已降级为提示，不再硬拒）**：「多年以后」「从这一刻开始」「深吸一口气」「毫无疑问/不容置疑」类判断套词——真人写作也会用，少量保留无妨；成片复现时再替换。
- **否定翻转 / 铺排**：「不是A而是B」「没有X没有Y」——直接写肯定内容，或用具象动作承担对比。
- **万能状语**：「，带着……」——删掉状语或换具体动作。
- **tell-not-show**：「他知道/感到/意识到/明白」——用行为展示认知，而非告知读者。
- **套式反应**：眼中闪过/嘴角勾起/瞳孔…/指节泛白等成片出现时，逐处删除只标注情绪却无信息的身体细节。
- **套词密度**：仿佛/一丝/一抹/深吸一口气等成串复现时，整段回到角色当下的动作、物件、后果。
- **比喻密度**：好像/仿佛/如同成片出现时，保留一两个最有功能的，其余改白描。
- **弱化副词**：微微/淡淡/缓缓/轻轻 每千字超过 3 个时，孤立自然使用可保留，成串时替换。

## 报告格式

自检完成后用 3~6 行汇报：
- ✅/❌ 逐项结论（字数 / 推进 / 情绪流+爽点 / 钩子 / 禁忌 / 格式 / 一致性 / 去AI味）
- 有 ❌ 的项：说明问题并**直接修复**，修复后再确认。
- 全部通过才向用户宣告本章完成。
