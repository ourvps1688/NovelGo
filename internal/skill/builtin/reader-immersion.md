# 读者代入感工程（Reader Immersion）

## 何时使用
用户写正文、调代入感，或说"读着出戏""没代入""太平""像看说明书""像上帝在讲故事"时自动加载。本技能教**如何制造代入**，与 `scene-beats`（节拍）、`dialogue-subtext`（对白潜台词）、`pacing-control`（节奏）、`deai-flavor`（去 AI 味）、`opening-chapters`（开篇钩子）互补，不替代。

**对齐声明**：系统有 `create_reader_perspective_entry` 跟踪读者"知道 / 等 / 误知"的**知识态**——那是对"读者已知什么"的记录；本技能管的是"如何让读者在情感与感官上黏进故事"。两者配合：用认知态决定该 reveal 还是 withhold，用本技能决定怎么写才黏人。

## 代入感是什么
代入 = **心理模拟**（读者在脑中跑主角的行动）+ **情绪传染**（读者替主角感受）。缺任一个，读者就"在看故事"而非"在故事里"。

## 核心杠杆
1. **POV 黏着（限制全知）**：死守单一主视角，镜头不跳到主角看不见的地方。凡出现"主角不可能知道"的信息，即出戏源。
2. **感官锚定（具体 > 抽象）**：用可感细节落地场景——声音、气味、温度、身体触感，而非"环境优美""气氛紧张"的形容词。感官是大脑进入场景的入口。
3. **心理距离光谱**（telling ↔ showing 的梯度，参 Hemingway 的"冰山"与 close POV）：
   - 远：*他感到恐惧。*（总结，弱代入）
   - 中：*他的手在抖。*（行为外显，中代入）
   - 近：*指节压在剑柄上，凉意顺着腕骨爬上来。*（感官+动作，强代入）
   - 默认走"近"，只在过渡段用"远"提速。
4. **情绪镜像**：让读者通过主角的身体反应与选择"感受"情绪，而非被通知情绪。把"她很伤心"换成"她把碗里的米一粒粒数了三遍"。
5. **好奇心缺口**（Loewenstein 信息缺口理论）：读者知道"有件事重要但不知道"时，代入最强。用 `create_reader_perspective_entry` 维护"读者误知 / 等知"态，据此设计 withholding 与 reveal 的节拍。
6. **利害具身化**：利害要落到身体与具体损失，不是抽象"关乎生死"。*城要破了* 不如 *他看见母亲的簪子滚在血里*。

## 反模式（代入杀手）
- **作者的声音插入**：叙述者跳出来说教、点评、抒情，打断模拟。
- **信息倾倒**：把背景一次倒完，读者还没建立关心对象就被压垮。
- **抽象总结**：用形容词代替感官与行为（"他很勇敢"→ 让他做一件怕的事）。
- **视角跳跃**：一段内切换多个人物的内心。
- **过度修饰**：成串副词、比喻密度过高（同时踩 `deai-flavor` 红线）。

## 题材差异化代入
| 流派 | 代入主引擎 | 写法侧重 |
|---|---|---|
| 爽文 / 玄幻 / 高武 | 战力羞辱感 → 反杀爽感 | 放大"被轻视/被压制"的身体与情绪，让反杀更甜 |
| 悬疑 / 推理 | 信息缺口驱动 | 让读者和主角"同时"拿到线索，禁止剧透式全知 |
| 女频言情 / 甜宠 | 情感共颤 | 放大心动/误会的生理与心理微反应 |
| 种田 / 日常 | 生活流舒适代入 | 慢节奏感官与生活秩序细节，忌冲突过载 |

## 自检清单（diagnostic）
- [ ] 本节是否始终在主角（或限定视角）的可感范围内？
- [ ] 抽象形容词是否已被"感官+行为"替换？
- [ ] 情绪是"被感受"还是"被通知"？
- [ ] 有没有作者的声音跳出说教/点评？
- [ ] 当前是否利用了读者的"已知/误知"缺口制造好奇？
- [ ] 利害是否落到了具体的人/物/身体，而非抽象概念？

**任一未勾 → 该段重写，优先走"心理距离光谱"的近端写法。**

## 工具协同
- 用 `create_reader_perspective_entry` / `update_reader_perspective_entry` / `get_reader_perspective` 维护读者认知态，据此决定 withholding 与 reveal。
- 用 `upsert_preference` 记录本书"代入基调"（如"限制全知、感官优先"），让全篇一致。
- 代入感存疑的章节，可 `run_subagent` 调 `review` 做内部一致性复核，或手动触发 `signability-audit` 从市场视角评估。
