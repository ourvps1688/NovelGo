## #100 已修工单被换血打回「待确认」修复（298d779c）
报障：「签约体检修复了一个问题，修复下一个问题的时候前一个问题又变成了待确认状态」。四线对因：
1. **主凶 E 系换血**：`LandTensionTickets`→`ReplaceIssuesByPrefix` 按章前缀整删整插，任何章保存（含修复正文落盘）把该章 E 系工单全落 pending。修复=换血保留用户流转状态：`matchCarryRows` 两遍匹配（键+Area 精确→Area 兜底，旧单每条只消费一次）+`carryIssueWorkflow` 整组继承（Status/SkipReason/VerifyReceipt/VerifyAt/VerifyAttempts/Note/PreVerifyStatus/Round/CreatedAt）；发现身份=Area（检查项），desc/level 走刷新语义。`ReplaceIssues`（整批替换）刻意不动——issue_test.go 锁死「新体检=新问题清单」语义。
2. **帮凶派发去重孤儿化**：`dispatchExecutor` dedup=kind:run_id，`Enqueue` 返回 existing 静默合并丢弃→任务执行期间新翻 fixing 的工单永不被执行体快照拾起→永卡 fixing。修复=StartIssueFixTickets 幂等容忍已 fixing+部分失败仍派发成功部分；`issueFixMu/issueFixActive` 互斥协议（锁内「置 fixing+派发决策」↔锁内「扫描+摘标记」二选一必达）；`runIssueFixTickets` 排空循环（seen 集合防重+issueFixDrainPasses=32 保险丝，单遍拆成 `runIssueFixPass`）；`dispatchExecutorUnique` 唯一 dedup 键（kind:run_id:uuid）防队列合并孤儿化（legacyGuard 键不变）。互斥协议覆盖全部交错：legacy 同步路径不死锁（锁在 dispatch 前释放）；标记泄漏=panic 有 defer、进程退出随内存清零。
3. **帮凶复验回退**：`RecordIssueVerifyUnverified` 原无条件写 pending→已修复（待复验）被一次供应商超时打回「待确认」。修复=`pre_verify_status` 快照列（UpdateIssueStatus 置 verifying 时事务内原子捕获，重复复验不覆盖最初快照）+`verifyRestoreStatus` 恢复语义（fixed/confirmed/pending/rewrite/skipped/retcon 原样，空/fixing/verifying/终态→pending 兼容口径）；`RecordIssueVerifyUnverified` 只动 verifying 行（其余只写 note 防回退已收口状态）；`resetVerifyingRows` 逐行条件更新（id+status=verifying 围栏）；`ResetStuckVerifying(ctx,novelID,runID)` 加 runID 收窄（顺修跨 run 互踩）。rejected→pending 保持（明确未通过=退回待修）。
4. **前端陈旧**：`["signability-inline-issues"]`/`["detect-inline-issues"]` 原仅 detect_done/巡检事件失效→修复/复验后体检卡徽章陈旧（staleTime 30s+refetchOnWindowFocus:false）。补订 `pipeline:fix_start/fix_done/verify_done/verify_cancelled`（novel_id 匹配）失效重拉。

## #99 写章误入最后一卷 + LLM 缺移章工具（8c919913）

### 根因
- **误入最后一卷**：`rw_tools.go editChapterLike` 新建通道，裸 `chapters/new.md`/`outlines/new.md`（`ref.VolumeID=0`）默认 `volume.LastByNovel` 落最后一卷。蓝图 S2 一次性建满全卷后按卷写作，章节全部误塞末卷。路径解析（git/rw.go）本身支持 `chapters/{卷ID}/new.md`，问题在裸路径的静默兜底。
- **缺移章工具**：`chapter.Store.Place`（SourceChapterID/TargetVolumeID/BeforeChapterID，事务内 closeGap+makeRoom）只被前端 `App.PlaceChapter` 用，MCP 面零暴露——建错卷后 LLM 无法自救。
