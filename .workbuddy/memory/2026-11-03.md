# 2026-11-03 一致性巡检修复（卡死根治 + 归并超时）

## 背景
用户长期投诉一致性巡检「一直检测中/卡死」。前序会话把巡检收敛为单次 `consistency-patrol`
调用（commit 0da8355c），但暴露两个根因：
- 单次收敛时**漏注入 `buildPatrolCorpus`**（`【本书语料】`= 章正文+台账快照），LLM 仅拿到台账+预筛簇
  却禁用工具 → 无书内容、判断空转；
- 预筛 `EmbedBatch`（本地 ONNX）**无超时**，异常时同步阻塞 → 整轮巡检永久卡死（零 LLM 调用、零日志）。

## 修复（两笔提交，均已 push，sync 0 0）
1. `d0d8ff72` fix(pipeline): 一致性巡检注入全书语料 + 预筛限时
   - `runConsistencyPatrol` 现注入 `buildPatrolCorpus` 拼成的【本书语料】作为唯一完整证据源；
   - 预筛套 90s 短超时（`prescreenCtx`）；`clusterPrescreenCands` 的 `EmbedBatch` 包 goroutine+select(ctx.Done)
     兜底，ctx 超时必返回，底层 ONNX 即便仍阻塞在后台也不影响主流程；
   - `synthesizePrompt` 文案改引用【本书语料】。
2. `2b0335a2` fix(pipeline): 归并超时 20min→45min
   - 全书语料注入后提示词体量约为旧方案的 5~10 倍，思考模型通读全书并吐完整 JSON 张力报告
     耗时显著增加，原 20min 在收口 JSON 前即触发 context deadline（实测 01:37 patrol 跑满 20min 被掐断，
     模型已通读 chapters 1-13 并在分析候选矛盾点，但未能收口 JSON）；

## 三次修复：输出 token 硬上限（commit d58abf3a）+ 端到端验证成功
- 二次修复仍不够：语料收紧到 40% 后**思维量不按比例缩**（task 106 跑到 33min 仍未收口即被 dev 重建打断），
  思维块膨胀与语料体量基本无关，模型按自己节奏空转（~50 token/s，task 105 满 45min 时思维 210k 字符）。
- 三次修复（d58abf3a）：归并调用加 **patrolSynthesizeMaxTokens=48k 输出 token 硬上限**。
  链路：SkillInput.MaxTokens → agent.RunOptions.MaxTokens → llm.CallOptions.MaxTokens → payload max_tokens
  → MiMo 钩子映射 max_completion_tokens（思考+回答总量）。MiMo 无 ReasoningLevels，推理档位不可用，
  输出上限是唯一可靠杠杆；48k 给足精简思考空间（报告 JSON 仅 2~4k token），最坏生成 ~16min；
  触顶截断时 parseFreshAudit 降级落清晰失败态。
- **端到端验证成功（task 107, 11:22→11:38）**：verdict=needs_fix 真实张力报告落 gate_objects（id=204）：

  全字段（fix_type/target_scope/dimension/direction/chapter_ids）；exec_run_stats status=ok、16.8min；
  llm_usage purpose=patrol output_tokens=35094（<48k 上限，模型自然收口）。对比：task 105 45min 失败 → 107 17min 成功。

## 排障/环境要点（延续）
- Go 工具链在 `C:/Program Files/Go/bin`；pre-commit hook 需 `export PATH=...go/bin:...mingw64/bin:...go/bin` 才找得到 go/golangci-lint。
- `git commit` 钩子在找不到 go 时会报 “no staged Go files / gopfmt not found” 但仍可能已建对象；提交后务必 `git rev-list --left-right --count origin/master...HEAD` 核实 `0 0`。
- wails dev 必须用工具 `run_in_background` 起（裸 `nohup ... &` 会被工具回收进程树杀死）；重启前用 PowerShell `Stop-Process` 真 PID 杀 wails + 子 node，再起。
- `App.d.ts`/`App.js` 每次 wails 重建会冒噪声，提交前 `git checkout --` 还原。
