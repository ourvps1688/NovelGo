## 心智提取「流式响应为空」修复：工具调用非流式回退（已提交推送 b374e89 → master）

- 用户报错「提取模式失败: [0] 流式响应为空」：根因是第三方服务商/中转不支持「流式 + tools」组合，SSE 零产出即结束（`parseSSE` 零产出检测触发，StatusCode=0 来自 `APIError.Error()` 格式 `[code] msg`）。
- 修法（internal/llm）：① stream.go 零产出错误加 `Kind: "empty_stream"`；仅 hasReason 无 content 时错误信息改为"只有推理内容"（区分 max_tokens 不足/推理失控）。② 新增 `toolcall_nonstream.go` 的 `callToolNonStream`：复用 buildPayload（仅关 stream/stream_options），兼容 arguments 为字符串或裸 JSON 对象（`unquoteIfNeeded`）。③ `calltool.go` 的 `CallTool` 捕获 empty_stream 后自动回退非流式一次，成功即返回，失败聚合进既有重试。
- 单测 4 个（`calltool_test.go`）：回退成功/对象 arguments/正常流式不回退/双失败聚合。httptest 按 payload.stream 分流。
- 教训：手写 SSE JSON 转义易错，测试里用 `json.Marshal` 构造 chunk。
