## 启动 dev 端口 5173 被占用（wails dev 残留）
- 报障：`wails dev` / `npm run dev` 起 Vite 时 `Error: Port 5173 is already in use`（vite 默认端口）。
- 根因：`wails dev` 拉起的 `node ... vite.js` 子进程**不会随父 wails.exe 一起死**，端口一直挂着；下次再起 dev 就冲突。
- 排查：`Get-NetTCPConnection -LocalPort 5173` → `OwningProcess` 即占端口的 node PID（Vite）；其父是 `wails.exe dev`。
- 修复：把 `wails` 父进程 + `node vite.js` 子进程 + 失败的 `npm run dev` 一并 `Stop-Process -Id <pid> -Force`，端口即空（本次 17988/23360/43096 三进程，清后 5173 无连接）。
- 教训：停 wails dev 必须父子同杀；以后起 dev 前若报端口占用，照此清端口再起。
