# 2026-10-18

## 读者视角筛选器计数联动修复

- 用户反馈：读者视角里同时选「悬念」和「未回收」时，顶部显示「悬念 67 条」，下面显示「未回收 242 条」，数字看起来矛盾。
- 根因：`ReaderView.tsx` 里类型筛选数字和状态筛选数字都直接对**全部 entries** 做统计，没有互相联动。两个 tab 数字独立自全局数据取，导致视觉不一致。
- 修复（提交 `daeff58`，已推送 `ed505bd..daeff58`）：
  - 类型 tab 数字（已知/悬念/误解）现在会按当前选中的状态（全部/未回收/已回收）过滤后计数。
  - 状态 tab 数字（未回收/已回收）现在会按当前选中的类型（全部/已知/悬念/误解）过滤后计数。
- 验证：前端门禁全绿（tsc/prettier/i18n:check/theme:check/eslint 0 error/vite build）。
- 注意：前端改动需 `npm run build` 并重启 `wails dev` 才在 webview 生效。
