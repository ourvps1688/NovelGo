### 技能价值结论（可证伪事实）
- 写章技能是**静态**的：`buildWritingSkillBundle` 只在命中 `next` 时触发（`app/slash_command.go:208-225`），输入仅章号/任务卡/`RhythmTemplate`/消息文本（`writing_skill_conditions.go:42-67`），**不读 finding、不读上一章检测结果、不读质量档案**。每章同一套：固定 3 技法 4,946 rune + 最多 2 个条件技能 3,000 + `next` 2,433 ≈ 7.4k–10.4k rune。
- 技能正文与检测器**不同源**：技能给「前 1000 字法则 / 每 800 字微钩子 / ≥3 Try-Fail / 第一句出事 / 开篇最炸」（平台卡与方法论），检测器用 `openingSlopeWindowRunes=500` rune、`openingSlopeMinRise=5.0`、`tensionSegTargetRunes=400`、`pacingDragMinRun=3` 及冲突/动作/短句词表（`internal/quality/tension_checks.go:17-22`）。写作侧 system 与检测同源的**只有单章字数**（`chapter_words.go:186-190 SystemLine`），其余零成文约束。
