## 排障经验（本轮新增，已录 MEMORY.md）

- **wails dev watcher 会失活**：一次 rebuild 后对后续 Go 保存零反应（touch 也无效；日志无
  [Rebuild triggered]、novelgo-dev.exe mtime 停滞、models.ts 缺新字段）。判据三件套：
  日志 rebuild 计数 + 二进制 mtime + models.ts 是否含新 DTO 字段。处置=按重启铁律整机重启
  （TaskStop 旧任务→Get-Process 清残留→全套 export+CODEBUDDY_SAFE_DELETE_ENABLED=0+
  换新日志名 wails-dev-0021.log 重拉）。本次 02:05:28 二进制只含前半批改动（issue.go/
  service.go/detect_status.go 全没进运行态），靠重启补齐。
- **git commit 含 Go 文件必须在同一条命令里带全套 export**：pre-commit 钩子的 golangci-lint
  需要 go/GOCACHE/GOLANGCI_LINT_CACHE/LOCALAPPDATA，缺失直接 BLOCKED（"go not found"）。
  纯前端提交无感（钩子跳过 Go 检查），以前没暴露。shell 状态不跨命令持久。
- **react-hooks purity 规则**：render 里禁 Date.now()/new Date()（"Cannot call impure function
  during render"，error 级）。合规模式=SubagentCard/useTimeAgo 同款：useState(() => Date.now())
  + useEffect setInterval 走针（回调里 Date.now() 不算 render）。new Date(str)/Date.parse(str)
  纯解析不触发。
- **无 sqlite3 CLI 时查任务表**：`node -e "const {DatabaseSync}=require('node:sqlite'); ..."`
  （Node 22+ 内置，readOnly:true）查 build/bin/novel-agent.db；tasks 表 status 只有
  queued/running/done/dead 语义，非终态查询 `status NOT IN ('done','dead')`。
- wails 重启重产 App.d.ts/App.js 纯排序噪声（CancelIssueVerify 位置挪动）照旧 git checkout
  还原；models.ts 本次 diff 干净（仅 DetectionTaskStatus 两新字段），直接入库。
- **`npm run build` 会撞死 dev 里的 app**：前端 build 闸门重写 dist/assets 时 wails dev 的
  assetserver panic（assethandler ServeHTTP 栈），novelgo-dev.exe 静默退出而 wails 工具不拉起
  （日志停更 + wails/reload connection refused）。判据=队列轮询日志停更超 1 分钟；
  处置=重启 dev。教训：前端 build 闸门跑完后检查 dev 是否存活，或把 build 闸门挪到 dev 重启前。
