## 00:27 dev 忽然白屏 —— 根因是 Wails dev 的 localhost 双栈绑定错配（按用户选择仅冷启动恢复，未改配置）

**现象**：21:00 冷启动的 dev 跑了 3.5 小时后，00:27 前端忽然白屏。

**结论：不是代码问题、不是昨晚「后台自动修复下线」那次改动、不是 watcher 失活、不是渲染进程崩溃。**

### 决定性判据（curl 加 `--noproxy '*'` 排除 curl 自身代理干扰）

```
http://127.0.0.1:34115/   → 200        （Wails dev server，只绑 IPv4）
http://[::1]:34115/       → 超时失败
http://127.0.0.1:5173/    → 超时失败
http://[::1]:5173/        → 200        （Vite 8，只绑 IPv6）
```

Wails dev 让 WebView2 加载 `http://localhost:34115` 并由 wails 转发到 Vite 的 `localhost:5173`，两个服务分别只监听一个 IP 栈。`localhost` 在 Windows 上的双栈解析优先级会变（DNS 缓存刷新 / 网络切换 / 渲染进程重建），某一侧重载解析到不匹配的一侧 → 页面取不到资源 → 纯白而不报错。佐证：到 5173 的 TCP 连接只剩一条 `TimeWait`，HMR 长连接已断且未重连。

**排除项（逐项实证）**：
- 后端健康：`novelgo-dev` PID 2428 存活，00:30 仍在正常写 SQLite、跑完 statesync（`run_subagent` elapsed 295826ms success）。
- WebView2：18 个 `msedgewebview2` 进程全部 `Responding=True`，主渲染 319MB，StartTime 仍是 21:00:59 那批（无崩溃重启）；Go 467MB / Vite 228MB，非 OOM。
- Vite：`/`、`/src/main.tsx`、`/src/lib/wailsjs/go/app/App.js` 全部 200 且正常编译。
- 源码：`frontend/src` 自 21:02:19 后 3.5 小时零改动，`git status` 干净；日志里零 JS error / panic / HMR error / `Rebuild triggered`。
- 重建 exe size 与旧版字节一致（79769313），也是「源码没变」的佐证。

**两个不是根因的观察（勿误判）**：

- 数学互斥：`emotionScore = 8 + 92*(0.60 情绪词密度 + 0.40 感叹/反问)`，`climax` 要 `emotion>=70`；去 AI 味禁直白情绪词/感叹号 ⇒ 无论怎么改都到不了峰值 ⇒ `beat_gap/beat_density` 永远挂着。`openingSlopeFinding` 旧式取「末段 − 首段」，文案却要求「前置冲突抬首段」，方向相反。`ReplaceTensionCurve` 先删后插不存旧值，下一轮 LLM 拿不到新旧曲线。
- 技能面：写章技法包只在 `next` manual 轮注入；改稿轮走普通 chat 路由，常命中 `revision-pass(auto)` 或 internalOnly redirect，固定 3 技法完全不注入；`rewrite_method` 定向通道生产零调用点；1500 rune 单技能帽恰好截掉 `reader-immersion` 自检清单和 `scene-beats` 平台数字模板。唯一真实模型实测是意图分类 92.6% / 负面误触发 0%，**无运行态证据指向供应商能力瓶颈**（无回退率/截断率/解析失败率落库）。
- 结论：不是供应商，是「双链断裂 + 判定器目标互斥 + 提示词缺可执行处方 + 状态层无已修概念」；技能是次要放大器。

**用户选择**：`P0 判定器+处方单源（推荐）`（P1/P2 仅列为后续方案，未实施）。
