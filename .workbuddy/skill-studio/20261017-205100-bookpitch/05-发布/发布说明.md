## 版本与变更说明
- book-pitch skill `version: 1 → 2`。
- 前端集成从 v1（整表覆盖 + 自动保存）升级到 v2（增量 + 手动保护 + 冲突提示）。
- 行为变更：用户手动改过的字段不再被 AI 后续建议静默覆盖；出现冲突时给予提示并可一键「采用 AI 建议」。

## 依赖与前置条件
- 无新增运行时依赖；`book-pitch.md` 经 `go:embed` 嵌入，**需 Go 重新编译 / 重启 `wails dev` 生效**。
- 前端需重新 `npm run build` 并经 `wails dev` 加载新 dist 后才在 webview 生效（见项目约定：前端改动必须重建 dist）。

## 安装 / 验证步骤
1. 拉取本提交，重启 `wails dev`（触发 Go 重编 + 前端 build）。
2. 书架点「AI 孵化新书」→ 输入灵感 → 开始 → 与 book-pitch 聊到定稿。
3. 预期：chat 末尾 JSON 块不显示；表单自动填满；书架卡片书名/简介同步更新。
4. 手动改某一字段（如书名）→ AI 再输出新 JSON → 该字段保留手动值，其余更新，并弹冲突提示。
5. 点「采用 AI 建议」→ 全部字段以最新 AI JSON 覆盖并保存。
